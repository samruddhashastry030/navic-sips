# Weight image format

Generated by python/ml/export_weights.py from `sim/lstm_l1only/lstm_h8_l2.pt`.
The RTL must match this exactly.

## Numeric format

Signed 16-bit two's complement, Q8.8 (8 fractional bits, LSB = 0.003906).
Two values per 32-bit SRAM word: even slot index in bits [15:0], odd in bits [31:16].

## SRAM map (512 x 32 = 1024 slots)

| slot | contents |
|---|---|
| 0-1 | normalisation mean, feature 0 and 1 |
| 2-3 | RECIPROCAL of normalisation std dev, feature 0 and 1 |
| 4 | SEVERE decision threshold |
| 5-68 | lstm.weight_ih_l0 32x2 |
| 69-324 | lstm.weight_hh_l0 32x8 |
| 325-356 | lstm.bias_ih_l0 32 |
| 357-388 | lstm.bias_hh_l0 32 |
| 389-644 | lstm.weight_ih_l1 32x8 |
| 645-900 | lstm.weight_hh_l1 32x8 |
| 901-932 | lstm.bias_ih_l1 32 |
| 933-964 | lstm.bias_hh_l1 32 |
| 965-988 | head.weight 3x8 |
| 989-991 | head.bias 3 |
| 992-1023 | zero padding |

Tensors are flattened row-major. LSTM gate order inside the 4H rows is PyTorch's: input, forget, cell, output.

## Gate LUTs

`lut_sigmoid.hex` and `lut_tanh.hex` hold 256 Q8.8 entries each, covering input range [-8.0, +8.0] uniformly.
Index = round((clip(x, -8.0, 8.0) + 8.0) / 16.0 * 255).
These live in ROM, not the weight SRAM.

## Inference

Input is `(raw_S4 - mu) / sd` per feature, 32 timesteps, 2 features. Run 2 LSTM layers of 8 hidden units, take the final hidden state, apply the head, then predict SEVERE if P(SEVERE) >= threshold else argmax of the other two.
